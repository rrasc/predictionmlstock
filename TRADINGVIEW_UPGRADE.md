## 🎯 How to Use

### Start the Real Data API:

```bash
# Install dependencies (if needed)
pip install flask flask-cors pandas numpy scikit-learn requests

# Start API server
python real_data_api.py
```

You'll see:
```
🚀 REAL DATA API SERVER
✅ Using Yahoo Finance public API (100% FREE!)
📊 Real stock prices - no API keys needed
🤖 Machine Learning predictions
📈 TradingView-style data

🌐 Server: http://localhost:5000
```

### Open the Frontend:

```bash
# Serve the new trading interface
python serve_frontend.py
```

Then open: http://localhost:8000/index_trading.html
